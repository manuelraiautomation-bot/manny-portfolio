# Portfolio app demonstrations

MealPilot and Lanie are independent static demos, not production clients. All customers, amounts and inventory are fictional. State is versioned in this browser's localStorage; Reset demo replaces only that demo's data. No production APIs, accounts, credentials or synchronization are used. A restrictive CSP disallows network connections.

MealPilot demonstrates request → allocation → cumulative sales report → remittance review → partial owner confirmation. Sales are ₱10 per meal, commission is ₱1, and collections increase only on owner confirmation.

Lanie demonstrates timed rentals at ₱10/hour, customer records, payments, save/resume, transfer and charging status. Save/resume and transfers preserve original charges and payments. The demo does not implement production background notifications, five-device sync, refunds, or the complete financial history.

The portfolio case studies describe the original applications. These demos intentionally cover selected workflows. The Lanie walkthrough and English captions are hosted separately in /demos; they show demo data.
